## 📋 Project Overview

A complete full-stack To-Do List application with:
- **Frontend:** React.js with responsive UI
- **Backend:** Node.js/Express REST API
- **Database:** SQLite (file-based, no external DB needed)
- **Containerization:** Docker with multi-stage builds
- **Deployment:** Render.com (manual + automated CI/CD)
- **CI/CD:** GitHub + Render Blueprint

## 🚀 Features

- ✅ Create, Read, Update, Delete tasks
- ✅ Mark tasks as complete/incomplete
- ✅ Edit existing tasks
- ✅ Persistent storage with SQLite
- ✅ Responsive design for mobile/desktop
- ✅ Docker containerized
- ✅ Automated deployment on Git push
